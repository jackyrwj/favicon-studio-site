Privacy policy

Favicon Studio processes only the information needed to recolor website favicons. It does not operate a developer server, collect analytics, sell data, or use data for advertising.

Effective date: August 7, 2026 · Last updated: August 7, 2026

Information the extension handles

Favicon Studio may handle the following information on your device:

  • The hostname of the website in the active tab.
  • The favicon URL and favicon image declared by a website.
  • Your selected preset theme or custom color pair.
  • Hostnames for which you explicitly save a site-specific preference.

The extension does not read page text, form entries, passwords, cookies, personal communications, or browsing history unrelated to its favicon feature.

How the information is used

The information is used only to preview, recolor, apply, and restore website favicons. Hostnames are used to match a saved theme preference to the correct website. This processing supports the extension's single purpose and is not used to build a browsing profile.

Local storage and retention

Theme preferences and associated hostnames are stored in chrome.storage.local in your browser profile. They are not synchronized by Favicon Studio and are retained until you change them, clear the extension's local data, or uninstall the extension.

Network requests

When a theme needs to be previewed or applied, the extension may request the favicon from the website or icon host chosen by that website. These requests omit cookies and other credentials. The destination server may receive ordinary connection information such as an IP address and browser request headers, as it would for a normal image request. Favicon Studio does not send your saved preferences or a browsing log with that request.

Sharing, sale, and advertising

Favicon Studio does not transmit information to the developer, sell user data, share user data for advertising, use data for personalized advertising, or allow humans to read user data. It does not include analytics, tracking SDKs, or remotely hosted executable code.

Permissions

  • Storage: saves global and site-specific color preferences locally.
  • Scripting: initializes the extension's packaged content scripts in regular web pages that were already open when you installed or updated the extension. This happens only after you select a theme and does not load remote code.
  • Website access: reads and replaces favicon elements and retrieves favicon images on websites where the extension operates.

Your choices

You can keep the original icon for an individual site, turn off the global theme, clear the extension's local storage from Chrome, or uninstall the extension. Uninstalling removes the extension and its locally stored preferences from Chrome.

Policy compliance and changes

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. If Favicon Studio's data handling changes, this policy and the extension's prominent disclosures will be updated before the changed handling begins.

Contact

For privacy questions or deletion help, use the support contact provided on Favicon Studio's Chrome Web Store listing.
