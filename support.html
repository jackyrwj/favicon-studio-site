Support

Get Favicon Studio working

Choose a theme and Favicon Studio will initialize supported tabs that were already open—no manual refresh is normally required.

The favicon did not change

Open Favicon Studio and choose a theme for the current site. If the icon still does not change, refresh that page once and try again. Chrome-protected pages such as chrome:// pages and the Chrome Web Store cannot be modified.

A site should keep its original icon

Choose Current site, then select Keep original. This site will be excluded even when a global theme is active.

Reset the global theme

Choose All sites, then select Turn off global. Existing site-specific choices remain unchanged.

Still need help?

Use the support contact or Support hub on Favicon Studio's Chrome Web Store listing. Include your Chrome version, the affected website, and the steps that reproduce the issue. Do not include passwords or private page content.
